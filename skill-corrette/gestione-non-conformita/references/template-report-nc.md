# Template Report Settimanale Non Conformità — Field Project SAS

Destinatario: GILI, che decide l'eventuale inoltro a SAC/DLL. Usa sempre
questa struttura (intestazione, riepilogo, NC in evidenza, trend); il testo
della nota di trend è libero.

```
FIELD PROJECT SAS
Coordinamento Attività di Montaggio

REPORT SETTIMANALE NON CONFORMITÀ

Cantiere: [nome/codice]
Periodo: [DD/MM] – [DD/MM/YYYY]
Direttore di Cantiere: [nome] — Field Project SAS per GILI Creations
```

## Riepilogo

| Indicatore | Valore |
|---|---|
| NC aperte nel periodo | N |
| NC chiuse nel periodo | N |
| NC attualmente aperte | N (di cui X critiche) |
| NC scadute (oltre SLA) | N |
| % chiuse entro SLA (periodo) | X% |

|---|---|---|---|---|---|---|
| NC-... | ... | ... | ... | 🔴/🟠/🟡 | ... | ... |

## Trend

Breve nota (2-3 righe): tempo medio di chiusura per gravità rispetto
al periodo precedente, fornitori con NC ricorrenti se il pattern è
evidente.

## Tono
Professionale, fattuale, orientato all'azione — ogni NC in evidenza
deve avere un'azione e un responsabile associati, non solo una
descrizione del problema.
